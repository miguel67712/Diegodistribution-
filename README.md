# Swift Send Forms

Build a modern, professional, mobile-responsive form submission website for my enterprise.



I will attach the following materials:



- The enterprise logo

- An image/document containing the services offered

- The exact form/syntax that customers currently fill out

- The WhatsApp number that should receive the submissions



Main Goal



The purpose of this website is to replace the current process where customers fill out a form, take a screenshot, and manually send the screenshot on WhatsApp.



Instead, customers should complete the form directly on the website and click a “Submit via WhatsApp” button. The website should automatically format all the information they entered into a clean WhatsApp message and open WhatsApp with the message ready to send to the provided WhatsApp number.



IMPORTANT



Carefully analyze all the attached files/images before building the website.



- Reproduce the form fields from the attached form/syntax accurately.

- Do not invent unnecessary fields.

- Use the attached enterprise logo prominently but professionally.

- Use the attached services information to create a clear services section or service selector where appropriate.

- Use the WhatsApp number provided in the attachments/configuration as the destination number.

- Preserve the meaning and order of the original form while improving its visual presentation and usability.



Website Structure



Create:



1. Header

   

   - Enterprise logo

   - Enterprise name

   - Clean navigation

   - Mobile-friendly menu



2. Hero Section

   

   - Professional headline explaining that customers can submit their request/application online

   - Short description

   - Clear call-to-action button that takes the user to the form



3. Our Services

   

   - Display the services from the attached material

   - Use professional cards/icons

   - Keep the design clean and easy to understand



4. Online Form

   

   - Recreate the exact form requirements from the attached material

   - Use appropriate input types:

     - Text fields

     - Phone number

     - Email

     - Dropdown/select

     - Date

     - Textarea

     - Checkboxes/radio buttons where necessary

   - Mark required fields clearly

   - Add proper validation

   - Show helpful error messages

   - Make the form very easy to complete on a mobile phone



5. WhatsApp Submission

   

   - Add a prominent “Submit via WhatsApp” button at the bottom of the form.

   - When clicked, validate all required fields.

   - Convert the completed form into a professionally formatted WhatsApp message.

   - Open WhatsApp using the appropriate WhatsApp link/deep-link method.

   - Send the message to the enterprise's WhatsApp number.

   - The customer should NOT need to take a screenshot.

   - Do NOT send the information to a random number or placeholder.

   - Use the WhatsApp number supplied in my attached materials.

   - Make the generated WhatsApp message easy for the recipient to read, with clear labels and spacing.



Example format:



📋 NEW FORM SUBMISSION



👤 Name: [customer name]

📞 Phone: [phone number]

🛠️ Service: [selected service]

📍 Location: [location]



📝 Additional Information:

[customer's response]



Please process this request accordingly.



Adapt this format to ALL fields contained in the actual form I provide.



6. Success/Confirmation

   After the user clicks the WhatsApp button, display a clear confirmation/instruction such as:

   “Your information has been prepared for WhatsApp. Please tap Send in WhatsApp to complete your submission.”



Make it clear that WhatsApp itself may require the customer to press the final Send button.



7. Contact Section

   

   - Display the enterprise WhatsApp number

   - Add a “Chat on WhatsApp” button

   - Display relevant contact information from the attached materials



8. Footer

   

   - Enterprise logo

   - Enterprise name

   - Services summary

   - WhatsApp contact

   - Copyright



Design Requirements



Make the website look like a real professional business website, not a basic HTML form.



- Modern and elegant UI

- Clean typography

- Professional spacing

- Attractive cards

- Subtle animations

- Smooth scrolling

- Responsive on phones, tablets, and desktops

- Mobile-first form design

- Use the enterprise's logo/branding as the visual inspiration

- Use a professional color palette based on the attached logo

- Strong visual hierarchy

- Clear buttons and labels

- Accessible contrast

- Avoid unnecessary visual clutter



Technical Requirements



- Build the project with a clean, maintainable component structure.

- Use React with TypeScript if appropriate.

- Use Tailwind CSS or the project's existing styling system.

- Keep all form data in the frontend unless a backend is genuinely required.

- The WhatsApp submission should work without requiring a WhatsApp API or paid third-party service.

- Properly URL-encode the generated WhatsApp message.

- Make sure the WhatsApp link works on both mobile and desktop.

- On mobile, it should open the WhatsApp application when available.

- On desktop, it should open WhatsApp Web when appropriate.

- Do not expose sensitive API keys or credentials in the frontend.

- Include loading/processing states where useful.

- Prevent submission when required fields are incomplete.

- Preserve entered information if validation fails.



Final Quality Check



Before finishing:



- Compare the finished form against the attached original form/syntax.

- Make sure every required field is included.

- Make sure the services match the attached information.

- Make sure the enterprise logo is correctly used.

- Make sure the WhatsApp destination number is correct.

- Test the generated WhatsApp message with realistic sample data.

- Ensure no screenshot is required at any stage.

- Ensure the website is fully responsive and professional.
